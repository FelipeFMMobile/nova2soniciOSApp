## Validação e limites

Swift VoiceCore; regressões Go, Python e integração Go → LiteLLM → Spring fake.
O teste integrado verifica canários de bloqueio antes/depois, login de dois
usuários, confirmação, remoção opcional, replay, versão divergente, tentativa

retorno de suspensão em dispositivo e conversa Nova real. A restauração do
Keychain após reinício foi validada no simulador na continuação abaixo.

VoiceCore aprovado; builds macOS e iOS Simulator aprovados. Gates Go de build,
test e race aprovados. A revisão vet encontrou uma cópia de atomic no teste
A→B; o teste foi corrigido para abrir uma conexão independente, sem copiar locks.
Os três testes live (guardrails, identidade/perfil e AgentSession v2 com A2UI)
passaram nas imagens reconstruídas. Os canários e fixtures ficaram no stack
